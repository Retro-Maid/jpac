## 3. 47県結合時の県境（残件 2.4 — 解決）

e-Stat の注意事項は「都道府県の境界線は、接合処理を行っていないため、都道府県を
またがって市区町村を接合した場合には、都道府県の境界線にずれが生じる場合があります」と
明記している。**これを直接測った。**

47県の `HCODE`=8101 ポリゴン **231,668 件を1本の空間インデックスに統合**し、
jpac の代表点 **191,106 件**を通した。

| 結果 | 件数 | 割合 |
|---|---|---|
| 自分の市区町村に落ちた | **190,440** | **99.652%** |
| 別の市区町村に落ちた | 590 | 0.309% |
| どのポリゴンにも落ちない | 76 | 0.040% |
| **複数のポリゴンに落ちた** | **1** | **0.001%** |

**複数ヒットは1件のみ**で、それが唯一の都道府県跨ぎでもあった:
`13120`（練馬区）の代表点が `11230`（新座市・埼玉県）と `13120` の両方に入る。

> ✅ **残件 2.4 解決。県境の未接合による重なりは、19万点に対して 1 件。**
> 実運用上、`candidate_count > 1` の分岐は必要だが、量的な問題にはならない。

不一致 590 件のうち **551 件は静岡県（浜松の区再編）**。残る約 39 件が全国の境界付近である。

| | 発行元が名乗る版 | 利用できる日付シグナル |

### 6.2 位置参照情報 19.0b が最新か（1.2）— **未解決**

`https://nlftp.mlit.go.jp/isj/` と `_choose_method.cgi` を取得したが、版数はこれらのページに
無い。`config/sources.yml` は `version_source: "版数 column of _choose_files.cgi"` と
記録しており、**版数の確認は取得側（このリポジトリの外）の責務**である。

> **本リポジトリからは確認できない。** 取得側で確認する項目として引き継ぐ。

### 6.3 e-Stat 属性値の測地系 — **未解決だが影響なし**

定義書（JGD2000 版）の末尾に「属性情報については、JGD2000の値」とある。
JGD2011 版の属性値がどちらかを確かめるため、**JGD2000→JGD2011 のズレが最大級の宮城県**で
`X_CODE`/`Y_CODE` とポリゴン重心を 3,000 件比較したが、**代表点と重心は定義が異なるため
判定できなかった**（東西中央値 3.4m、南北中央値 -1.0m）。

> **設計上の影響はない。** `estat_small_area` は `X_CODE`/`Y_CODE` を持たず、
> 結合には `.prj` が JGD2011 と確定しているジオメトリだけを使う。
> **`X_CODE`/`Y_CODE` は取り込まない**ことを設計に明記する（`AREA`/`PERIMETER` と同じ理由）。
