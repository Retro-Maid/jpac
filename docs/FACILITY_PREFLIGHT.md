# 施設 → 市区町村（preflight）

国土数値情報の施設系ポイントレイヤを、バス停（`docs/BUS_STOP_PLAN.md`）と同じ型で
市区町村に結ぶための下調べ。取得元・版・結合方法の実測を記録する。

ライセンスの判断は `docs/LICENSE_REVIEW_FACILITY_2026_09.md`。人の確認は同 §1 であって、
この文書ではない。

結論を先に書く。

- **利用許諾がオープンデータの版に限ると、施設系ポイントレイヤで残るのは4つだけ**:
  P29 学校（2023年度）、P05 市町村役場等及び公的集会施設（2022年）、P04 医療機関（2020年度）、
  P36 高速バス停留所（2023年度）。
- **警察署・消防署・郵便局・公共施設・都市公園などは使えない。** 最新版を含めて「非商用」で、
  旧約款では複製物の再配布が除外されている。福祉施設（P14）は「一部制限」つきで、県・施設
  種別ごとに公開不可の条件がある。
- **最初は P29 学校と P05 役場等。** どちらも発行元が行政区域コードを持ち、点の位置と
  照らした一致率は P29 が 99.78%、P05 が 99.87%。
- **スコープの追加が要る。** `docs/POLICY.md` §3 は facilities・schools を V1 の対象外と
  しており、駅（§3.1）やバス停（同 2026-09-17 追記）と同じく、メンテナの判断で §3.1 に
  追記する必要がある（§6 に案）。

## 2. 実測（全国、2026-09-27）

方法は本番と同じ読み込み経路（`payload.read_dbf` / `read_shp_shapes`）。境界は e-Stat 小地域の
陸地ポリゴン 231,661件（`estat.is_land_polygon`）。どのファイルも shp・dbf の件数は一致した。

### 2.1 P29 学校（56,807件）

**行政区域コード**は全件が jpac の市区町村に解決した。

| | 件数 |
|---|---:|
| 直接一致 | 56,396（99.28%） |
| 旧浜松市の区を承継記録で1:1に読み替え | 349 |
| 分割された旧北区（22135、中央区と浜名区の2候補） | 62 |
| jpac にも承継記録にも無いコード・空欄・政令市の親コード | 0 |

**属性コードと点の位置の一致**

| | 件数 |
|---|---:|
| 1つに確定する一致 | 56,682（99.78%） |
| 分割による2候補 | 62 |
| **不一致** | **63**（うち県をまたぐもの2） |
| 点がどこにも入らない | 0 |

不一致の63件を所在地の文字列と照らすと、**所在地が点の側と合うもの（属性コードの誤り）が
55件、所在地が属性コードの側と合うもの（点の誤り）が8件**だった。どちらの側も自動では
勝たせられない。

- 泰明小学校：コードは千代田区、所在地は中央区銀座（点も中央区）
- 東京工業大学：コードは大田区、所在地は目黒区大岡山
- 仙台白百合学園幼稚園：点が大和町に落ちる（所在地とコードは仙台市）

**一意キー**：`(学校コード P29_002, キャンパスコード P29_008)` が 56,807件すべてで一意。
P11 と違い、発行元のキーがある。版をまたいで値が安定するかは未検証。

学校が0件の市区町村は、北方領土6村と熊本県水上村。水上村は要確認（「水上学園」1校が
43506 で入っている）。

### 2.2 P05 役場等・公的集会施設（79,532件）

| | 件数 |
|---|---:|
| 行政区域コード：直接一致 | 79,346（99.77%） |
| 承継記録で1:1 | 162 |
| 22135 の分割 | 24 |
| jpac に無いコード | 0 |

| | 件数 |
|---|---:|
| 属性コードと点が1つに確定して一致 | 79,430（99.87%） |
| 分割による2候補 | 24 |
| **不一致** | **65**（うち県をまたぐもの1） |
| 点がどこにも入らない | 13（出羽島・馬島などの島嶼や海岸。e-Stat 境界の隙間） |

**P05 の所在地は検証に使えない。** 先頭の市区町村名が属性コードから作られているらしく、
コードが誤っていれば所在地も同じく誤る。

- 江南市古知野町の施設が「常滑市古知野町…」として常滑市のコードで入っている（9件）
- 花見川区の施設12件が稲毛区のコードで入っている

いずれも**点が正しく、コードと所在地が誤り**だった。

**一意性**：`(コード, 名称, 所在地)` が重複する組が11ある。座標まで含めると一意。
P11 と同じく代理の行 ID（`p05_facility_id` など）が要る。

施設分類（`P05_002`）の内訳：本庁 1,908、支所・出張所 4,272、その他の行政窓口 2,562、
公民館 21,302、集会施設 49,488。

### 2.3 参考：P04 医療機関・P36 高速バス停留所

- P04：1つの市区町村に入るのが 181,175、どこにも入らないのが 4、2つに入るのが 0。
  所在地と明確に食い違うのは 66件（0.036%）で、佐賀県鹿島市の施設が茨城県鹿嶋市に落ちる
  ような、県をまたぐ誤ったジオコーディングを含む。
- P36：1つに入るのが 9,217、どこにも入らないのが 3、2つに入るのが 1。

## 3. 結合

バス停は点だけで結んだが、P29・P05 は**発行元の行政区域コードがある**。これを主にし、
点の突き合わせを**独立の検証**に使う。

1. **属性コードを解決する。** 直接一致、または承継記録（`municipality_lineage.yml`）の
   1:1 で解決したら候補にする。
2. **点の突き合わせと同じ市区町村なら確定する**（`auto`）。
3. **食い違ったら両方を候補に残す**（`candidate_count = 2`、`review_required`）。どちらかを
   選ばない。P29 の実測では、正しいのがコード側のことも点側のこともあった。
4. **点がどこにも入らないときは、属性コードの候補を残し、単一の根拠であることを
   `match_method` で区別する。**
5. **分割された旧北区（22135）は既存の承継記録の仕組みで2候補にする**（`review_required`）。
6. **所在地の文字列は一致の確定に使わない。** 食い違いの検知にだけ使う
   （住所文字列によるジオコーディング結合はしない）。

粒度は市区町村で止まる。`address_id` 列は持たない（`POLICY.md` §3.1）。点の座標は
リリース成果物に出さない（§3.1）。地図に出すかどうかは §3.2 の別の許可になる。

## 4. 危ういところ

- **国土地理院の承認の種類。** P29 は「測量法に基づく国土地理院長承認（使用）」、P05 は
  「国土地理院長の承認を得て…数値地図25000（地図画像）を使用」を掲げている。N03 の採用を
  止めた根拠（`docs/N03_BOUNDARY_DESIGN.md` §8）は「**複製**」の承認と利用者への警告だった。
  今回はどちらも「**使用**」の承認で、その警告は無い。人が判断すべき点。
- **P05 の出自。** 市役所の位置は P02 公共施設（非商用）から取っており、原典には第三者の
  「全国公民館連合会『全国公民館名鑑』（2005年版）」が含まれる。現在の CC BY 表記を覆す
  材料ではないが、確認に回す。
- **文字コード。** P05・P04 には `.cpg` が無い。cp932 で読むと GeoJSON 側と42セルで
  食い違った（「－」の U+FF0D と U+2212、「～」の U+FF5E と U+301C）。どちらを原本として
  読むかを決め、アダプタに固定する。P29 は UTF-8 の `.cpg` がある。
- **コード表と実データの食い違い。** P29 の休校区分 `P29_007` は、コード表では
  0＝調査なし／1＝開校中／2＝休校中。実データはコード表に無い **9 が202件**あり、2 は0件。
  取り込み時に止めて確認する。
- **ページ記載のサイズは当てにならない。** P29 全国ファイルはページで 1.13MB、実測は
  5,443,235 bytes。SHA-256 で固定する。
- **入れ子 zip。** P05 の全国ファイルは中に47県の zip を持つ。P11 と同じ
  `open_zip_bytes_safely` の経路を使う。
- **断面。** どちらも浜松市の区再編（2024年）より前のコードで、既存の承継記録がそのまま効く。

  independent check, and a disagreement keeps both candidates.

  editions are 非商用 and are never mixed.
