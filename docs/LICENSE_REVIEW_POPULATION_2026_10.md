## 2. 規約上の筋道

- e-Stat 利用規約は、jpac の既存ソース `estat_boundary`（2026-09-14 審査）と同じ規約で
  ある（廃置分合等情報 `estat_municipality_change` も同じ規約で 2026-09-27 に署名済み。
  PR #30、未マージ）。結果表は e-Stat 本体の
  コンテンツなので、e-Stat 利用規約が直接適用される。
- 2026-10-12 に規約ページの本文ハッシュ（`snapshot.license_text_hash_bytes`）を再計算し、
  ベースライン `93c44dc2fc4de2f33789c71ca80bceac80877ee42f4b707a69d345bc3ff28fa1` と
  一致した。規約は 2026-09-14 の審査から変わっていない。
- 規約は「数値データ、簡単な表・グラフ等は著作権の対象ではありません」と書いている。
  それでも出典表示と加工の記載は行う（既存の e-Stat ソースと同じ扱い）。

### 2.1 面積と人口密度を除く理由

第1-1表の注記5:

> 「面積（参考）」については、国土交通省国土地理院「令和７年全国都道府県市区町村別面積調（10月１日時点）」による。

人口密度は注記6のとおりこの面積から算出される。国土地理院の承認や第三者の原典を掲げる
データは採らない、という既存の判断（P29・P05 を 2026-09-28 に中止）に合わせ、**2列とも
取り込まない**。`config/sources.yml` の `excluded_columns` に理由とともに記録する。

### 2.2 出典表示（案）

```
「令和7年国勢調査 人口等基本集計」（総務省統計局、政府統計の総合窓口（e-Stat）、https://www.e-stat.go.jp/）を加工して作成
```

## 3. ⚠️ AI による下読み（人の判断ではない）

以下は AI が 2026-10-12 に読んだ内容であって、§1 の人の確認を置き換えるものではない。
P11 の審査では AI の下読みが一度誤答している（`docs/LICENSE_REVIEW_P11_2026_09.md` §3）。

**e-Stat 利用規約**（<https://www.e-stat.go.jp/terms-of-use>）:

> イ　本利用ルールは、平成２８年１月２９日に定めたものです。本利用ルールは、政府標準利用規約（第2.0版）に準拠しています。

> ウ　本利用ルールは、クリエイティブ・コモンズ・ライセンスの表示 4.0 国際（…）と互換性があり、本利用ルールが適用されるコンテンツはCC BYに従うことでも利用することができます。

別紙に挙がっているのは次の6つで、統計表のファイルダウンロードは含まれていなかった。

- 政府統計の総合窓口（e-Stat）のロゴの利用について
- 公的統計のミクロデータ利用ポータルサイト（miripo）及びミクロデータ利用電子申出窓口（e-Micro）のロゴの利用について
- ＡＰＩ機能の利用について
- 統計地理情報システムの利用について
- ミクロデータ利用電子申出窓口（e-Micro）の利用について
- 調査票情報提供機能の利用について
